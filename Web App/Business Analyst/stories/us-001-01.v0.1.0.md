# US-001-01: sign in with correct email and password

## Definition

As a **registered account holder**, I want to **sign in with correct email and password**, so that **gain access to the app so that valid login attempts succeed and redirect to /home, driving the authentication success KPI**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given a registered user enters their correct email and password on the login page, when they click "Sign in", then the server validates credentials against the stored bcrypt hash, returns a session cookie, and redirects the user to /home
- [[AC-001-01-02]] — Given a registered user enters their email with different casing but correct password, when they click "Sign in", then the system behaves per the documented email-matching behavior (treat as exact match unless stated otherwise) and either succeeds or fails consistently with stored credential comparison
- [[AC-001-01-03]] — Given the login form is missing a password, when the user clicks "Sign in" without entering a password, then the request is rejected before hitting credential validation and the Sign in button or form prevents submission
