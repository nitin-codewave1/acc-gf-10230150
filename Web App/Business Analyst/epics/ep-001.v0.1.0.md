# EP-001: Login UI & Credential Authentication

Build login page (email/password fields, Sign in button) and POST /api/login endpoint that validates credentials against bcrypt hashes, issues session cookie, and redirects to /home on success. Directly drives reliable authentication KPI.

**Objective:** [[OBJ-001]]

## Stories
- [[US-001-01]] — sign in with correct email and password
- [[US-001-02]] — see a generic error when entering wrong credentials
- [[US-001-03]] — be locked out after 5 consecutive failed login attempts
- [[US-001-04]] — receive a secure, time-limited session cookie after successful login
- [[US-001-05]] — use a visible login form with email, password, and a Sign in button
- [[US-001-06]] — have failed login attempts validated server-side against bcrypt hashes rather than client-side
